本文档定义蒸馏简报的 **输出格式**。AI 在输出时必须严格遵守本模板，不得改变章节顺序，不得省略必填要素。

## 默认输出规则（最重要）

**首轮只生成 L0 卡片并暂停**，不自动连续输出三档。L0 结尾必须给出明确的下一步选项，等待用户指令：

- 首轮（无显式档位指令）= L0 30 秒决策卡片 + 定位问题（A 算法研究 / B 临床部署 / C 不确定），结尾提示「**回复『继续』看 3 分钟速览（推荐）；回复 A/B/C 确认目标后出完整审计；回复『完整』直接出十章**」——推荐项放最前，减少"再回一轮才见实质内容"的摩擦
- 用户说"继续"/"精简"/"3 分钟" → L1 五块
- 用户说"完整"/"详细" → L2 十章
- 用户说"审计"/"JSON"/"专家" → L3（L2 + JSON 审计日志）
- 用户首轮明确说"直接出报告/完整+方向" → 允许一次输出 L0→L1→L2，三档分别校验

**档位顺序裁决（强制）**：展开 L2 时，L2 必须以"## 第零章：跨学科全景扫描"开头；首轮 L0 卡片不需要第零章标题。用户的定位回答（A/B/C）是 L1/L2 结论方向的输入，展开时按已确认目标重估结论，不沿用 L0 的条件化占位结论。

此裁决取代任何"首轮前 20 字必须含第零章标题"的旧规则。`validate_output.py` 通过必填的 `--level` 参数识别档位，L0 不校验第零章。

## 禁止内部黑话（全档位强制，违反则输出无效）

**用户输出中禁止出现的内部术语**：
- 禁止：§14、§1、threshold_note、CORE_EVIDENCE_THRESHOLD、score_evidence.py、validate_output.py、SKILL.md、output-template.md、plain-language-map.md、evidence-rubric.md、mode_router、L1/L2/L3/L4 推理层、rule2_triggered、mock_fallback、valid_evidence_count、detailed_scores、base_weight、decay_factor、confidence_multiplier
- 禁止：任何脚本名、文件名、配置键名、内部章节编号、内部规则编号

**必须翻译成人话**：每写完一段，检查是否有内部术语泄漏。有则替换为人话。用户看到的是结论和数字，不是规则名、脚本名、文件名。

**术语对照表**（内部→人话）：

| 内部术语（禁止出现） | 用户视角的人话 |
| :--- | :--- |
| level=green/yellow/red | 证据强/中/弱 |
| total_score=9.25 | 加权总分 9.25（满分 8.0 为强证据门槛） |

| unverifiable_count=0 | 0 篇无法验证 |
| rule2_triggered | 有效证据为 0，结论基于推断 |
| Conference_paper | 会议论文 |
| Literature_review | 期刊综述 |
| RCT | 随机对照试验 |
| Meta_analysis | Meta 分析（汇总多项研究） |
| Systematic_review | 系统综述 |
| Diagnostic_accuracy | 诊断准确性研究 |
| External_validation | 外部验证研究 |

## 标签双轨（人读符号 ↔ 机读文字）

| 人读层 | 机读层 | 含义 |
| :--- | :--- | :--- |
| ✅ | 【确证】 | 有直接证据支持 |
| 🔶 | 【推断】 | 基于间接证据或常识 |
| ❓ | 【无法判断】 | 无可用数据 |

- 渲染 L0/L1 时用符号；L2/审计日志中只存文字标签。
- 连续 3 处无标签的校验规则不变。

**置信度标签体系（每条判断必须三选一，标注在句尾【】内）**：

| 标签 | 含义 | 适用条件 |
| :--- | :--- | :--- |
| 【确证】 | 有直接证据支持该判断 | 至少 1 篇同行评审论文或官方公告直接支持 |
| 【推断】 | 基于间接证据或行业常识得出 | 相关但非直接证据，或基于工程常识的合理推测 |
| 【无法判断】 | 无可用数据支撑 | 检索结果为空或全部不相关 |

**强制降级规则**：若第十章"有效论文"数量为 0（含全模拟数据），全文所有【确证】标签自动替换为【推断】，并在第六章或第九章注明降级原因。

### L0 渲染规则（硬约束）

1. **结论第一行出现**，不再读到第九章。结论来自等级矩阵判定，不得 AI 现编。
2. **证据分数硬规则**（违反则校验器报硬失败，必须重写）：
   - 直接展示核心证据分与满分，不使用进度条符号
   - 格式固定：`证据：{强/中/弱} 核心证据分 X.X（满分 8.0，≥8.0 为强证据门槛）`
   - 等级标签与分数一致：强=X.X≥8.0，中=4.0≤X.X<8.0，弱=X.X<4.0
   - 分数取 core 层合计分 total_core（不含预印本/模拟数据/待核验条目）
   - insufficient 写「⚪ 证据不足」（不显示分数）
3. **"下一步"必须来自验证动作**（第八章"验证动作一/二/三"），不能 AI 现编，禁止"第X-Y周"等隐含时间线的表述。
4. **结论符号**：🟢=强证据/优先整合，🟡=中等/持续追踪，🔴=弱/暂时搁置，⚪=证据不足。
5. **insufficient 时**：卡片不显示三选一结论符号，改显示「⚪ 证据不足」+ 一句话理由（说明缺哪类核心证据），不显示分数。
6. **总分<0.5 时**：卡片不显示结论，改显示「⚠️ 证据极度匮乏（{分数}），需你决策：A.扩大检索 B.你提供论文 C.低置信度推断」。
7. **有效证据为 0 时**：卡片顶部加红条「🔴 模拟数据 — 以下结论基于训练数据推断」，且不输出三选一结论，改显示「需你决策」。
8. **部分无法验证时**：卡片"有效"行显示 `{可验证篇数}/{总篇数} 篇可验证`，让用户知道有多少证据被实际计分。
9. 人话翻译必须查映射表，命中即用，未命中保留原文。
10. **禁止内部黑话**：卡片中不得出现任何内部术语（脚本名、文件名、规则编号、配置键名）。用户看到的是结论和数字。
11. **免责声明精简**：L0 文末用一句话精简版「本简报基于公开文献生成，不构成研究决策依据。」L1/L2/L3 用完整版。标题用「## 免责声明」，禁止把"每次蒸馏简报末尾必须原样附加，不得修改措辞"等对 AI 的指令性文字渲染给用户。校验器已支持 L0/L2 分级检查。

**用户指令"继续/精简"后输出。** L1 是第二档，首轮不自动展开。

**L1 硬要求（与 L2 去重）**：L1 是 L2 十章的精炼摘要，禁止整句重复 L2 内容。每块用 1-3 句话概括，不复制 L2 原文。

### L1 模板（五块）

| 块 | 来源章节 | 内容 |
| :--- | :--- | :--- |
| 一句话判断 | 第零章 | 结论 + 知识密度 + 核心挑战（3 行引用块） |

### L1 渲染规则

1. 每块标题用 `## 块名`，不得用"第X章"（避免与 L2 章节混淆）。
2. 标签用符号双轨（✅🔶❓），但每块末尾必须注明"详细证据见 L2 第X章"。
3. 证据索引块默认折叠：`<details><summary>Top-3 证据</summary>...</details>`。
4. mock_fallback 时，"结论+坦诚"块替换为「需你决策」红条，不输出三选一。

## 第零章：跨学科全景扫描（直觉判断，置信度 ≤40%）

## 第一章：跨域目标定位

**必填要素**：用自然段落描述本交叉学科方向要解决的「元问题」（1-2 段），以及涉及的学科范围清单（列出 ≥2 个学科）。不使用表格。

---

## 第二章：知识蒸馏路径拆解

**必填要素（≥2 条路径，自然段落，禁止表格）**：每条路径描述「从哪个学科蒸馏什么知识 → 输入到哪个学科产生什么价值」，每条 1-2 段。

例：
- **蒸馏路径 1**：从材料学科蒸馏柔性基底的生物相容性实验设计知识 → 输入到生物传感学科，用于解决传感器长期皮肤接触的炎症反应问题。【推断】

---

## 第三章：跨学科证据约束

**必填要素（≥2 条约束）**：每条约束描述一个学科的证据标准，并给出跨域整合时的归一化策略。

例：
- **约束 1**：生物医学学科的 RCT 证据权重为 5.0（参见 references/evidence-rubric.md §1），材料学科的原型实现权重为 1.5；跨域整合时采用加权平均归一化，避免单一学科权重主导总分。【确证】

---

## 第四章：待确认的交叉点假设

**必填要素（引用块格式，≥2 条）**：与第零章的假设对应，但更具体化、技术化。每条标注置信度和行动建议（确认或搁置）。


**必填要素 C：有效性状态 6 枚举说明（必须在表格下方给出）**：

- 【低影响力】：被引量显著低于同方向中位数，或年份较早但引用极少（判定依据 citation_count / influential_citation_count 字段，数据源 Semantic Scholar；无数据时禁止使用本状态，见下方兜底说明）
