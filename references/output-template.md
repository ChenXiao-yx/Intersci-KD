# InterSci-KD 输出模板：十章结构化知识蒸馏简报

本文档定义蒸馏简报每一章节的 **必填要素** 与 **置信度标签规则**。AI 在输出时必须严格遵守本模板，不得改变章节顺序，不得省略必填要素。

**置信度标签体系（每条判断必须三选一，标注在句尾【】内）**：

| 标签 | 含义 | 适用条件 |
| :--- | :--- | :--- |
| 【确证】 | 有直接证据支持该判断 | 至少 1 篇同行评审论文或官方公告直接支持 |
| 【推断】 | 基于间接证据或行业常识得出 | 相关但非直接证据，或基于工程常识的合理推测 |
| 【无法判断】 | 无可用数据支撑 | 检索结果为空或全部不相关 |

**强制降级规则**：若第十章"有效论文"数量为 0，全文所有【确证】标签自动替换为【推断】，并在第六章或第九章注明降级原因。

## 第零章：跨学科全景扫描（直觉判断，置信度 ≤40%）

**⚠️ 首轮回复必须以本章为开头，自然段落起手，禁止用 Step 1/2/3 标题。本章允许使用「模块预览」4 列表格，其他位置禁止工程表格。**

**必填要素（6 要素，缺一不可）**：

1. **先说结论**：（一句话概括该方向在跨学科图谱中的位置，≤30 字，建议优先整合 / 持续追踪 / 建议搁置 三选一）
2. **三行关键指标（引用块格式）**：
   ```
   > **知识密度**：（高密度 ≥50 篇 / 中等 10~49 篇 / 稀疏 <10 篇 — 基于相关学科近 5 年可检索文献产出量）
   > **核心科学挑战**：（一句话，≤30 字。如"传感器信号漂移"、"因果推断内生性难题"、"LTV vs CAC 取舍"）
   > **蒸馏优先级**：（优先整合 / 持续追踪 / 建议搁置）
   ```
3. **跨学科关联图谱**：
   ```
   > **学科A** — [学科名称]：核心贡献与关键进展
   > - 证据锚点：（至少 1 个可验证来源）
   > - 知识缺口：（该学科尚未解决的关键问题）
   >
   > **学科B** — [学科名称]：核心贡献与关键进展
   > - 证据锚点：（至少 1 个可验证来源）
   > - 知识缺口：（该学科尚未解决的关键问题）
   >
   > **交叉点识别**：（学科A ∩ 学科B 的核心交汇点，不超过 2 句话）
   ```
4. **模块预览（蒸馏路径）【本章唯一允许的 4 列表格】**：
   | 蒸馏层级 | 模块 | 描述 | 优先级 |
   | :--- | :--- | :--- | :--- |
   | 数据层 | 跨域检索 | 多学科文献自动采集 | P0 |
   | 特征层 | 证据分级 | 跨学科证据权重校准 | P0 |
   | 知识层 | 冲突消解 | 识别并调和跨学科矛盾结论 | P1 |
   | 应用层 | 图谱生成 | 输出结构化知识关联图 | P1 |
5. **待确认的跨学科假设（引用块格式，≥2 条）**：
   ```
   > 📋 **待确认的跨学科假设**
   > - **假设A**：（当前推测【置信度xx%】→ 请确认是否存在跨学科验证）
   > - **假设B**：（当前推测【置信度xx%】→ 请确认）
   ```
6. **一句话理由**：（一句话说明为什么该交叉点值得优先蒸馏）

## 第一章：跨域目标定位

**必填要素**：用自然段落描述本交叉学科方向要解决的「元问题」（1-2 段），以及涉及的学科范围清单（列出 ≥2 个学科）。不使用表格。

---

## 第二章：知识蒸馏路径拆解

**必填要素（≥2 条路径，自然段落，禁止表格）**：每条路径描述「从哪个学科蒸馏什么知识 → 输入到哪个学科产生什么价值」，每条 1-2 段。

例：
- **蒸馏路径 1**：从材料学科蒸馏柔性基底的生物相容性实验设计知识 → 输入到生物传感学科，用于解决传感器长期皮肤接触的炎症反应问题。【推断】

---

## 第三章：跨学科证据约束

**必填要素（≥2 条约束）**：每条约束描述一个学科的证据标准，并给出跨域整合时的归一化策略。

例：
- **约束 1**：生物医学学科的 RCT 证据权重为 5.0（参见 references/evidence-rubric.md §1），材料学科的原型实现权重为 1.5；跨域整合时采用加权平均归一化，避免单一学科权重主导总分。【确证】

---

## 第四章：待确认的交叉点假设

**必填要素（引用块格式，≥2 条）**：与第零章的假设对应，但更具体化、技术化。每条标注置信度和行动建议（确认或搁置）。

```

> - **假设 B**：（具体交叉假设【确证/推断】→ 建议：……）
```

## 第六章：知识获取成本与整合难度

## 第十章：多源证据锚点

**本章唯一允许使用 6 列宽表格的章节。所有其他章节不得超过 3 列。**

**必填要素 A：证据索引表（6 列完整格式，不得省略任一列）**：

| 序号 | 标题 | 所属学科 | 来源（DOI / PMID / 数据库 / URL） | 有效性状态 | 支撑结论 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | （论文标题） | 生物学 / 材料学 / 医学 / 社科 / 商业 | （DOI 或 PMID 或具体数据来源标识） | 有效 / 低影响力 / 已被修正或质疑 / 无法验证 | 支撑交叉点 / 不支撑 / 部分支撑 |
| ... | ... | ... | ... | ... | ... |

**必填要素 B：有效性状态 4 枚举说明（必须在表格下方给出）**：
- 【有效】：被引量处于合理范围，无撤稿或修正记录
- 【低影响力】：被引量显著低于同方向中位数，或年份较早但引用极少
- 【已被修正或质疑】：标题或摘要包含 retraction / correction / erratum 等关键词，或官方发布更正/撤稿通告
- 【无法验证】：缺少年份或被引量数据，或 DOI / PMID 解析失败，无法可靠评估

**兜底补充说明**：若检索脚本（search_papers.py / scp_tools.py）未返回具体被引数据（citation_count 字段缺失或为 null），AI 必须将对应论文的「有效性状态」统一判定为「无法验证」，不得主观臆断为「低影响力」。在支撑结论列追加短注释「缺少被引数据，默认降级处理」。

**必填要素 C：空检索兜底声明**：
若本次检索结果为空（无任何相关论文或公开数据），本章标注：

> *无可用文献证据，本简报完全基于 LLM 训练数据中的行业通用知识生成，所有判断置信度上限为 40%。*
